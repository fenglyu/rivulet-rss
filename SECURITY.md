# Security Policy

## Supported Versions

Security fixes are provided for the latest GitHub prerelease or stable release.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for this repository. If that feature is unavailable,
contact the repository owner through the private contact method listed on the
GitHub profile.

Include reproduction steps, affected versions, impact, and any suggested
mitigation. You should receive an acknowledgement within seven days.

## Scope

Rivulet fetches user-configured HTTP(S) feeds and can open HTTP(S) pages in a
local Chrome profile. Reports involving URL validation, browser profile
isolation, unbounded content, daemon process control, or malicious feed input
are especially useful.
